# EGO LITE 本机灰度

本次仅在本机启用，不发布采集端更新，不改变采集频率、并发配置、店铺 browser 字段或原 Chrome 目录。

## 接入

- Windows 官方安装包：`https://cdn.ego.app/setup/windows/x64/egoliteSetup.exe`，安装包版本 0.6.0.16，Authenticode 验证有效。
- 程序：`C:\Program Files\Citro Labs\ego lite\Application\ego.exe`。
- 本机配置：`.data/ego-pilot.local.json`；仅 `enabled: true` 且列于 `shop_ids` 的店铺使用 EGO。
- 灰度店铺：2（蓝怡宝家清旗舰店）、21（宇瑶清洁用品专营店）。
- 每店独立目录 `.data/ego-pilot/profiles/{shop_id}/v{profile_version}`，每店独立 CDP 端口 `19221 + shop_id`，仅监听回环地址。
- 原目录只做离线复制，未移动或覆盖。EGO 副本没有继承有效登录，用户已分别完成登录。
- 标识文件不匹配、独立目录未准备或程序缺失时阻止启动，防止使用错误资料目录。
- EGO 重启可能只恢复 `browser_ui` 欢迎页，忽略命令行网址。启动适配通过 CDP 显式创建店铺页；已有店铺页时不重复创建。

## 回退

在没有运行任务时关闭对应 EGO 店铺窗口，将本机配置的 `enabled` 改为 `false`，重启本机采集服务，即恢复原 Chrome 路径和端口。保留 EGO 副本供后续验证。不要把 EGO 升级后的资料反向覆盖到原 Chrome 目录。
