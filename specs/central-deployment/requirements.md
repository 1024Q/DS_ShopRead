# Windows 中心与独立采集节点

已确认：管理后台可部署在公网 Windows 主机；业务数据保存到独立 PostgreSQL；Windows 采集节点主动连接中心。保留现有单机运行方式及采集频率。

1. 中心启动时不应初始化浏览器、读取本地账号或启动采集调度。
2. 节点只发送业务结果与店铺展示信息，不传账号密码、浏览器资料或 API 密钥。
3. 店铺标识由节点 ID 与本机店铺 ID 共同组成，避免多机 ID 冲突。
4. 页面查询中心数据库；中心离线时节点继续原定采集；恢复后补传本地已发布结果。
5. 远程采集请求须鉴权、去重、持久化并支持超时重新领取；派发成功不能标记为采集完成。
6. 原有模块、远程控制、发票确认上传最终需要在中心入口完成适配；未适配前不可宣称与原工作台等价。
